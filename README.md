# N Notes (TWA)

N Notes is an experimental notes application built as a learning project.
It includes a web app, backend API, and an Android TWA wrapper.

The goal was to explore:
- Offline-first behavior
- Login & sync flows
- Running a web app as an Android Trusted Web Activity (TWA)

## What I Tried to Build
- A notes app that works offline first
- Syncs data after login
- Runs as an Android app using TWA (no address bar)

## What Went Wrong
I’m clearly missing some fundamentals, especially around:
- Address bar behavior in TWA
- Login flow and user experience
- Offline-first architecture decisions

The app works but not the way i intended.

## Tech Stack
- Frontend: Web-based (REACT/CSS)
- Backend: Node.js
- Android: Trusted Web Activity (TWA)
